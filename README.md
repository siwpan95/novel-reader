# 综网终端 · 地狱之下平台  ·  视觉小说版

> 仓库：<https://gitee.com/siwpan/novel-reader> ｜ 许可：MIT-0（MIT No Attribution）（见 [LICENSE](LICENSE)）
> 注：文中 <PATH> 为路径占位符，请替换为你本机实际的目录 / 可执行文件路径。

基于同名网络小说改编的 Tkinter 纯文字视觉小说游戏。
UI 以「综网终端」风格呈现，玩家以终端操作者身份接入地狱之下平台，浏览各世界档案。

## 世界观框架

```
源海 → 以太网络(综网) → 地狱之下平台 → 各游戏世界
```

- **源海**：终极混沌，所有宇宙的母体
- **以太网络**：覆盖多元宇宙的超级互联网
- **地狱之下平台**：综网旗下子平台，专收硬核高难度游戏
- **各游戏世界**：即各卷故事的舞台

---

## 运行方法

双击 `启动游戏.bat`，或在终端执行：

```
python game.py
```

**系统要求：** Python 3.10+（标准库，无需安装任何第三方包）

---

## 文件结构

```
hell_below_vn/
├── game.py              ← 游戏主程序（全部逻辑 + Tkinter GUI）
├── build_json.py        ← 地狱之下数据生成脚本
├── build_zuopinji.py    ← 关联档案数据生成脚本
├── 启动游戏.bat          ← Windows 一键启动
├── save.json            ← 档案存取文件（自动生成）
└── data/
    ├── meta.json        ← 世界/档案索引
    ├── lore.json        ← 世界观数据（终端启动文本、术语等）
    ├── vol_01~12.json   ← 地狱之下 11个世界
    ├── zuopinji_01.json ← 单机作家（设定圣典）
    ├── zuopinji_02.json ← 林东的无限崩坏之旅（平行宇宙）
    └── zuopinji_03.json ← 玩家之上（平台创始人视角）
```

## 操作说明

| 操作 | 效果 |
|------|------|
| 点击「继续 ▶」 | 下一页（+1 地狱点数） |
| 点击「◀ 上一页」 | 上一页 |
| `→` / `空格` | 下一页 |
| `←` | 上一页 |
| `Ctrl+S` | 档案存取 |
| `Escape` | 返回游戏库 |
| 点击「☰ 目录」 | 打开档案目录，直跳任意章节 |
| 「A+」/ 「A-」 | 调整字体大小 |
| 「💾 存取」 | 保存当前进度 |

## UI 世界观元素

| 元素 | 说明 |
|------|------|
| 🔥 地狱点数 | 每翻一页+1，完成章节+5，符合平台世界观 |
| ● 在线 | 终端信号指示器 |
| 终端开机动画 | 启动时逐行显示"连接以太网络"等文本 |
| CH./PG./PROG | 终端风格页码格式 |
| W-xx / A-xx | 世界编号/档案编号 |

---

## 数据架构说明

- `game.py`：负责全部游戏逻辑、界面渲染、存读档，**不含任何剧情文字**
- `data/*.json`：负责全部游戏文本，结构为 卷→章节→页 三级，**不含任何逻辑代码**
- `data/lore.json`：世界观数据，供 UI 运行时引用（启动文本、术语翻译等）

如需修改剧情文字，直接编辑对应 JSON 中的 `text` 字段即可。
